## 🚀 Cómo Abrir el Proyecto

Puedes abrirlo de dos maneras muy sencillas:

### Opción 1: Directo en tu Navegador (Doble Clic)
Simplemente haz doble clic sobre el archivo [`index.html`](file:///c:/Users/HP/Desktop/NOVAMOVIL/index.html) para abrirlo en Google Chrome, Microsoft Edge, Firefox o tu navegador favorito. Cuenta con soporte automático para funcionar tanto sin servidor como con servidor.

### Opción 2: Con un Servidor Local
Abre una consola PowerShell dentro de la carpeta y ejecuta:
```powershell
python -m http.server 8080
```
Luego visita en tu navegador: [http://localhost:8080](http://localhost:8080)
